# 🎓 Student Performance Prediction using Machine Learning

A Machine Learning web application that predicts student exam marks based on academic performance factors using **Linear Regression**. The project includes data preprocessing, model training, evaluation, and an interactive **Streamlit** web application.

---

# 🚀 Live Demo

🌐 **https://student-performance-prediction-ml-5jaqho3xgf5gcn7ywsd5em.streamlit.app/**

---

# 📌 Features

* 🎓 Predict Student Exam Marks
* 🤖 Linear Regression Machine Learning Model
* 📊 Interactive Streamlit Dashboard
* 📈 Prediction Confidence Display
* 📚 Clean & User-Friendly Interface
* ⚡ Real-Time Predictions
* 💻 Fully Deployable on Streamlit Cloud

# ▶️ Run Locally

Clone the repository

```bash
git clone https://github.com/faryadshahfs-byte/student-performance-prediction-ml.git
```

Move into the project directory

```bash
cd student-performance-prediction-ml
```

Run the Streamlit application

```bash
streamlit run App/07_streamlit_app.py
```
